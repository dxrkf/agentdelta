# English

Introducing AgentDelta: an offline, zero-dependency Python CLI that reviews permission drift in explicit AI agent capability inventories. Surface new actions, resource access and relaxed approval requirements before accepting a tool update.

Explainable findings, input hashes, JSON output and configurable CI exit codes. No tools are invoked. This is inventory review, not runtime enforcement.
